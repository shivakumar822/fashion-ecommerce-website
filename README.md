# Fashion E-commerce Website
Developed a responsive fashion e-commerce website using HTML, CSS, and JavaScript, featuring product listings, pricing, color options, navigation, and an interactive shopping interface with a clean and user-friendly design.
## Features

- Responsive fashion product layout
- Product listings
- Product pricing in Indian Rupees
- Product color options
- Navigation menu
- Interactive user interface
- Clean and modern design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. For development, use VS Code with Live Server.

## Project Preview

The website provides a simple and user-friendly interface for browsing fashion products.
